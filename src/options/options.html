Safety
Confirm before Delete
Show a confirmation dialog before deleting a page. Protected environments always ask for confirmation.
Confirm before Publish / Unpublish
Ask before Publish, Unpublish and Publish to Preview on every environment. Protected environments always ask, and you must type the page name.
Allow syncing to higher environments
Off: Sync only copies a page from a higher environment to a lower one (for example Prod → Stage), using the order set under Environment order. On: it also allows lower → higher (for example Dev → Prod), so the Sync menu shows both Pull and Push for every environment. Protected environments still need a typed confirmation.
Not available: Sync needs Developer Mode (or Developer persona) and its Sync toggle to be on. Your choice here is kept.
Desktop notifications
Show a system notification after Publish, Unpublish, Delete, Sync and similar actions. The toolbar message always appears; turn this off if the extra pop-up is noisy.
Keep passwords and tokens for this browser session only
Stores Basic-auth passwords and bearer tokens in memory instead of on disk. They are forgotten when the browser closes, so you enter them again next time. Browser Session login stores nothing either way. Click Save to apply.

Toolbar
Collapsed bar style
Use classic horizontal bar when collapsed
Replaces the default floating orb with a classic horizontal minimized bar (Edit, View, Live, Props). When off (default), the animated orb with its radial action fan is used. Changes apply the next time a page loads.
Open the orb at the pointer
Press and hold on empty page space to call up the orb right there. The spot isn't saved; it goes back after about 3 seconds with the pointer away, on Esc, or on a click elsewhere. Only applies when the floating orb is used. Changes apply the next time a page loads.
Toolbar buttons
Customise toolbar buttons
Choose which buttons appear on the regular and expanded bars, and in what order. When off, the standard toolbar is used. Your arrangement is kept while this is off. Changes apply the next time a page loads.
The logo, status, environment, Close, More and Settings buttons always stay. Anything you take off the expanded bar is still available from the More menu and the command palette.
The collapsed bar is shown as the default floating orb, which has a fixed set of buttons (Edit, View, Live, Environment, JCR or Copy path, Props and Sites), so its buttons can't be chosen here. Your arrangement is kept for when the classic horizontal bar is used.

Developer Mode
Developer toolbar controls
Enable Developer Mode
Show the developer-only actions (JCR, Overlays, Highlight, Inspect, Developer links, Reload, Delete, Sync) on the toolbar, in the More menu where they have a row, and in the popup's Developer Tools group. When off, only publish and navigation actions are shown.
Choose which developer actions are available when Developer Mode is on. Turning one off also removes its row from the More menu and the command palette, and its button from the popup where it has one.
JCR Inspector
Opens a panel with the page's jcr:content tree: browse and filter its nodes and properties, and compare them with another environment.
Toggle Overlays
Switches the AEM editor's edit overlays on or off, so you can see the page without the editing frames.
Highlight Components
Outlines the editable components on the page without shifting the layout.
Component Inspector
Hover or click a component to see its resource type and resource path. Copy either one or open it in CRXDE.
Developer links (CRXDE, Package Manager, JSON views, debug options)
A menu of developer views of this page: CRXDE Lite, .model.json and .infinity.json, wcmmode=disabled, client-library and layout debug options, and a no-cache reload.
Hard Reload
Reloads the page and bypasses the browser cache.
Delete Page
Deletes the page after a confirmation. Live pages are unpublished first, and pages that are still referenced are refused. Protected environments ask you to type the page name.
Sync Contents
Copies this page's content between environments (pull from or push to another one). It asks for confirmation, saves a version of the target page first, and by default only flows from a higher environment to a lower one.
