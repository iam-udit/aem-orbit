Chrome extension · Manifest V3 · 1.0.0-beta

Author, publish and inspect AEM content without leaving the page

AEM Orbit adds a floating toolbar to AEM Author, Preview, Publish and Dispatcher pages, plus a popup workspace for work that spans several pages. It works with AEM as a Cloud Service and AEM 6.5.

Download the beta Watch the video tutorial

The beta is installed as an unpacked extension: unzip the download, open chrome://extensions, turn on Developer mode and choose Load unpacked.

What it does

  • In-page Orb and toolbar

    A floating Orb opens a seven-leaf fan, or a full toolbar. Jump between Edit, View, Preview, Published and Live, and between Local, Dev, Stage and Prod on the same page.

  • Safe publishing

    Publish, unpublish, tree and bulk replication, with a reference check first, a dry run for trees, and a typed confirmation on protected environments.

  • Content sync

    Copy a page between environments with a property diff first, an automatic version backup, and one-click undo. By default content only moves from a higher environment to a lower one.

  • Developer inspectors

    A JCR tree, component and asset inspectors, Content Fragment details, a cache-header inspector, and deep links to CRXDE Lite, Package Manager and the JSON endpoints.

  • SEO and accessibility audit

    A page quality score with SEO and accessibility checks, and a link health scan, run on the page you are looking at.

  • Workspace popup

    Page search, cross-environment compare, versions, URL variants, quick links, an action history log, find and replace, and Dispatcher flush.

  • Edge Delivery and Universal Editor

    Recognises .aem.page and .aem.live hosts, switches between them, and opens the page in the Universal Editor.

  • Enterprise controls

    Managed policies can lock the settings and switch features off per environment, and brand profiles apply site-specific content roots and URL mappings.

Privacy and security

The extension has no analytics or telemetry and makes no calls to any server other than the AEM hosts you configure. It asks for access to those hosts only. With Browser Session sign-in it stores no credentials at all.
